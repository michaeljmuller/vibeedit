Build and run
=============

Layout
------

src/js/web/         Express server + Vite/React client (the only component)
src/docker/         docker-compose.yml, .env, web/Dockerfile
config/             allowed-emails.txt (gitignored, mounted read-only)
data/               Apple Dictionary files (gitignored, mounted read-only)
util/               helper scripts

Prerequisites
-------------

- Docker (dev) or rootless Podman (prod). Nothing else on the host.
- A Mac, once, to copy the dictionary files.
- API keys for Anthropic and ElevenLabs.
- A Google Cloud project with OAuth 2.0 credentials (see below).


1. Copy the dictionary files
----------------------------

On a Mac, open the Dictionary app, go to Dictionary > Settings and check:

- Oxford Portuguese Dictionary
- Oxford Paravia Il Dizionario

Wait for the downloads to finish, then run:

    util/setup-dictionaries.sh

This writes data/portuguese-english-dictionary.data and
data/italian-english-dictionary.data. If it cannot find them, locate them by hand:

    find /System/Library/AssetsV2/com_apple_MobileAsset_DictionaryServices_dictionaryOSX \
      -name Body.data | grep -iE "portuguese|italian"

and copy each Body.data to the file names above. For the server, copy the data/
directory over to the repo root there.


2. Set up Google OAuth
----------------------

See "Google Cloud Console setup" below.


3. Add allowed users
--------------------

Put one Google email address per line in config/allowed-emails.txt:

    you@gmail.com
    colleague@gmail.com


4. Create src/docker/.env
-------------------------

    cp src/docker/.env.example src/docker/.env

and fill it in. Generate the session secret with: openssl rand -hex 32

In production set GOOGLE_CALLBACK_URL to
https://edit.themullers.org/auth/google/callback.


5. Build and run
----------------

    cd src/docker
    docker compose build
    docker compose up -d

The app listens on host port 3000. GET /healthz is the healthcheck, and the
running commit is shown at the bottom of the user menu (also GET /api/version).


Google Cloud Console setup
--------------------------

1. Go to https://console.cloud.google.com

2. Create a project (or select an existing one) using the project dropdown at the
   top.

3. Enable the API: APIs & Services > Library, search for "Google People API", and
   click Enable.

4. Configure the consent screen: APIs & Services > OAuth consent screen.
   - Choose External (unless you have a Google Workspace org, in which case choose
     Internal: this skips verification and restricts to your org automatically).
   - Fill in App name (e.g. "VibeEdit"), User support email, and Developer contact
     email. Everything else can be left blank.
   - On the Scopes step, click Save and Continue (no extra scopes needed).
   - On the Test users step: if you chose External, add your own email and any
     other allowed users. While the app is in "Testing" status, only listed test
     users can log in. For a private tool, staying in Testing mode is fine.

5. Create credentials: APIs & Services > Credentials > Create Credentials >
   OAuth 2.0 Client ID.
   - Application type: Web application
   - Name: anything (e.g. "VibeEdit")
   - Authorized redirect URIs: http://localhost:3000/auth/google/callback and
     https://edit.themullers.org/auth/google/callback
   - Click Create

6. Copy the Client ID and Client Secret into src/docker/.env.
